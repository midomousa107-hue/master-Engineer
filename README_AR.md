# Master Engineer — مشروع Android Offline

## ما الذي أصبح موجوداً؟
- مشروع Android أصلي يستضيف واجهة محلية عبر WebView.
- لا توجد صلاحية INTERNET في Manifest؛ التطبيق لا يحتاج شبكة.
- قاعدة بيانات SQLite أصلية داخل الهاتف لحفظ سجل العمليات.
- محاكي Total Station تعليمي لحساب ΔE وΔN وإحداثيات النقطة.
- محاكي Level بطريقة HI.
- تحويل WGS84 Lat/Lon إلى UTM بحسابات Transverse Mercator تعليمية.
- مرجع أنظمة الإحداثيات ودروس GIS وRemote Sensing وحساب NDVI.
- الواجهة محفوظة محلياً داخل APK؛ لا تحتاج خادم أو اشتراك.

## بناء APK
يتطلب Android Studio أو Android SDK مع Gradle 8.7+ وJDK 17، واتصالاً أولياً لتنزيل Android Gradle Plugin وAndroid SDK platform إذا لم تكن مثبتة مسبقاً.
1. افتح مجلد المشروع `MasterEngineer_Android` في Android Studio.
2. انتظر مزامنة Gradle وتثبيت SDK Platform 35 عند الطلب.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ستجد APK في `app/build/outputs/apk/debug/app-debug.apk`.

## حدود هذه النسخة بوضوح
- هذا مصدر مشروع Android قابل للبناء، وليس ملف APK مبنياً أو موقعاً.
- لا يوجد حالياً اتصال فعلي بأجهزة Total Station أو Level أو GNSS؛ هي محاكيات حسابية تعليمية.
- الخرائط العالمية وصور الأقمار الصناعية غير مضمنة في هذه النسخة. إضافة خرائط Offline تتطلب تحديد المنطقة المطلوبة وحزم بيانات مرخصة قابلة للتوزيع.
- تحويل UTM لأغراض تعليمية؛ يجب التحقق من Datum وZone والمرجع الجيوديسي قبل استخدام أي نتيجة في عمل رسمي.
- زر EN/عربي يغيّر اتجاه الواجهة فقط حالياً؛ الترجمة الإنجليزية الكاملة مرحلة لاحقة.
- لم يتم اختبار APK على هاتف فعلي لأن بيئة التنفيذ الحالية لا تتضمن Android SDK أو Gradle مثبتاً.

## بناء APK عبر GitHub Actions مجاناً ضمن حدود الاستخدام المجاني
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد إليه.
2. افتح تبويب Actions واسمح بتشغيل workflows إذا طُلب ذلك.
3. شغّل `Build Master Engineer APK` من زر Run workflow، أو ادفع تغييرات إلى فرع `main`.
4. بعد نجاح التشغيل، افتح نتيجة التشغيل ثم Artifacts ونزّل `Master-Engineer-debug-APK`.
5. فك ضغط الملف وثبّت `app-debug.apk` على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من مصدر خارجي.

هذا المسار يحتاج حساب GitHub واتصال إنترنت أثناء عملية البناء والتنزيل فقط؛ التطبيق نفسه لا يطلب اتصالاً بالشبكة بعد تثبيته.
